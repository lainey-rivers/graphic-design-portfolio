# Lainey Rivers Creative Portfolio

A modern, interactive graphic design portfolio showcasing branding, web design, social media design, digital artwork, and front-end development.


## Features

- Responsive portfolio design
- Interactive project categories
- Project case studies
- Project galleries
- Full-screen image lightbox
- Previous/next image navigation
- Keyboard navigation
- About Me section
- Tools & technology section
- Contact section
- Copy email functionality
- Social media links
- Smooth scrolling
- Back-to-top button
- Responsive mobile layout
- Hover animations and glowing effects
